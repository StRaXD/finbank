## Intent

**Problem:** The scaffold has no design system. Later screens need the exact Finbank colours, Inter type scale, surfaces and brand assets from a single source. Without that, each screen would hard-code its own values and drift from the Figma PNGs.

**Approach:** Define all tokens once in `src/styles/tokens.css` under Tailwind v4 `@theme`, with chart-readable colours under `@theme static`. Load Inter and add the brand SVGs and a placeholder avatar to `src/assets/`. Replace the placeholder App with a token specimen. Add a test that fails if hex literals or arbitrary colour or font-size utilities appear outside `tokens.css`.

## Boundaries & Constraints

**Always:**
- **Token values** come exactly from `design-reference/design-system/Typography-color.png`:
  - **Colours:**
    - primary `#299D91`
    - neutrals `#191919 #525256 #666666 #878787 #9F9F9F #E8E8E8 #F3F3F3`
    - danger `#E73D1C`, positive `#4DAF6E`
    - on-dark: white/70%, white/8%, `#D2D2D2`/25%
  - **Type scale:** Inter weights 400–800. Size/line-height steps: 12/16, 14/20, 16/24, 18/24, 20/28, 22/32, 24/28.
  - **Surfaces:**
    - page bg `#F3F3F3`
    - card white, radius 8px, soft shadow
    - sidebar `#191919`
    - focus-ring token
- **Semantic names, not raw hex names.** For example `primary`, `ink`, `ink-2`, `muted`, `subtle`, `border`, `surface`, `danger`, `positive`, `on-dark-*`. Each type step is a `--text-*` token paired with its `--text-*--line-height`.
- **`@theme static`** holds every colour a chart may read from JS (primary, neutrals, danger, positive), so those colours always appear as CSS variables.
- **No literals outside `tokens.css`.** Hex literals and arbitrary colour or font-size utilities (`bg-[#…]`, `text-[13px]`, `text-[#…]`) are forbidden. A vitest check scans `src/**/*.{ts,tsx,css}`, excluding `tokens.css`, and fails on any.
- **Brand assets** live in `src/assets/brands/`:
  - `wordmark-teal.svg`, `wordmark-white.svg`
  - `google.svg`, `mastercard.svg`, `visa.svg`, `figma.svg`, `adobe.svg`
- **Logos** use the official brand-asset geometry and colours, not approximations.
- **Avatar:** a neutral placeholder at `src/assets/avatar-placeholder.svg`.

**Never:**
- **No UI primitives** (Button, inputs, Card and so on). Those are Story 1.3 and later.
- **No other code:** no routing, providers or feature code.
- **No new runtime dependencies** beyond what Open Questions settles.
- Do not use Tailwind's default palette colours in app code. Token utilities only.

**Decisions (human, 2026-11-16):**
- **Inter is self-hosted** via `@fontsource-variable/inter`, pinned exactly to the current npm latest. Import it once in `src/app/main.tsx`. No Google Fonts or other third-party font requests.
- **Wordmarks are outlined SVG paths.** Outline Poppins (Bold for "FINE" and ".IO", Regular for "bank") once into static paths, using a throwaway script in the scratchpad. Commit only the two SVGs. No runtime Poppins and no new repo dependency for it.

## Implementation Notes

- **Inter:** `@fontsource-variable/inter` pinned to `5.3.0` (npm `latest` on 2026-11-16), imported once in `src/app/main.tsx`. Family name is `'Inter Variable'`; `--font-sans` falls back to `Inter, ui-sans-serif, system-ui, sans-serif`.
- **Token names:** colours `primary`, `ink` (#191919), `ink-2` (#525256), `muted` (#666666), `subtle` (#878787), `faint` (#9F9F9F, placeholder text), `border` (#E8E8E8), `surface` (#F3F3F3 page bg), `danger`, `positive` sit in `@theme static`. `white`, `card`, `sidebar`, `on-dark`, `on-dark-muted` (white/70%), `on-dark-hover` (white/8%), `on-dark-divider` (#D2D2D2/25%), `focus-ring` sit in `@theme`. Type steps are `text-12` ... `text-24` (`--text-N` + `--text-N--line-height`). Also `--radius-card: 8px`, `--shadow-card`, `--focus-ring-width/offset: 2px`.
- **Defaults dropped:** `--color-*: initial` and `--text-*: initial` remove Tailwind's default palette and type scale, so `bg-red-500` / `text-sm` no longer exist. Spacing, containers and font weights keep Tailwind defaults (weights 400-800 are re-declared explicitly).
- **Shadow is an estimate:** `0 20px 25px rgb(118 118 118 / 10%)`, eyeballed from the screen PNGs; no Figma value exists. Revisit in Story 1.9 (Card).
- **Wordmarks:** outlined from Poppins Bold ("FINE", ".IO") and Regular ("bank") (google/fonts `ofl/poppins`) by a throwaway fontTools script in the scratchpad. Size and letter-spacing were least-squares fitted to the measured glyph ink columns of each PNG: Login teal fit = 41px Poppins, +7.1% em tracking (max glyph-edge error 1.4px at 1x); Overview white fit = 24.1px, +8.4% em tracking (max 1.2px at 1x). Each SVG is tight to its ink box: teal 271.3x30.7 at 1x, white 162.6x18 at 1x. The spec's "about 380x50 at 1x" is the Login PNG downscaled for display, not 1x: the PNG is 2880px wide (2x), and the ink is 542x60px there. No kerning applied (fit residuals did not need it). Overlay check against both PNGs at 2x showed edge-for-edge alignment.
- **Logo sources:**
  - `google.svg`: classic four-colour "G" (Google's standard sign-in mark paths), via https://commons.wikimedia.org/wiki/File:Google_%22G%22_logo.svg . Google's current official kit (https://developers.google.com/static/identity/images/signin-assets.zip) now ships the 2025 gradient "G", which does not match the Login PNG, so the classic mark was used; viewBox cropped to the mark.
  - `mastercard.svg`: symbol only (no "mastercard" wordtype, matching the screens), from the 2016 brand mark at https://commons.wikimedia.org/wiki/File:Mastercard-logo.svg ; overlap colour set to Mastercard's published #FF5F00 (the source had #FF5A00). The official brand center (brand.mastercard.com) requires a login.
  - `visa.svg`: Visa 2006 wordmark (blue + gold flourish, matching Balances PNG), from https://commons.wikimedia.org/wiki/File:Visa_Inc._logo.svg ; Visa's brand portal requires a login.
  - `figma.svg`: official "Figma Icon (Full-color)" from the Figma brand kit zip linked at https://www.figma.com/using-the-figma-brand/ ; viewBox cropped to the icon.
  - `adobe.svg`: official Adobe corporate mark, https://www.adobe.com/content/dam/cc/icons/Adobe_Corporate_Horizontal_Red_HEX.svg (polygons converted to one path, #FA0F00).
  - All logos were stripped of editor metadata and given `role="img"` + `aria-label`.
- **Avatar:** `src/assets/avatar-placeholder.svg`, neutral grey head-and-shoulders on #E8E8E8, circle-clipped.
- **Node-only tests are `*.node.test.ts`:** `src/lint-boundaries.node.test.ts` (renamed from 1.1), `src/styles/tokens.node.test.ts`, `src/design-literals.node.test.ts`, `src/styles/build-output.node.test.ts` and `src/assets/assets.node.test.ts`. `tsconfig.app.json` excludes and `tsconfig.node.json` includes the glob `src/**/*.node.test.ts`, so new node tests need no tsconfig edits.
- **Build-output test:** `build-output.node.test.ts` runs Vite's programmatic `build()` into a temp dir and checks the 10 chart `--color-*` vars, no default palette, the `body` and `:focus-visible` base rules, and the self-hosted Inter Variable `@font-face` plus woff2 asset. Removing the `tokens.css` import or the fontsource import fails it.
- **Derived tokens use `var()`:** `card` and `on-dark` reference `--color-white`, `sidebar` references `--color-ink`, `focus-ring` references `--color-primary`.
- **Literal scan also catches** functional colours (`rgb/rgba/hsl/hsla/oklch/oklab/lab/lch(`), `leading-`/`tracking-`/`font-`/`text-shadow-` arbitrary values, and arbitrary properties for colour, background, fill, stroke, font, line-height and letter-spacing. Named colours are not detected.
- **Literal scan has no exemptions beyond `tokens.css`:** the guard tests write their hex fixtures without `#` (or build them by concatenation) so they pass their own scan.
- **Specimen weights:** 12/14/16 regular, 18 bold, 20 medium, 22 bold, 24 semibold, read from `Typography-color.png`.
- **Vite inlines small SVGs** as data URIs (under 4 KB), so the specimen test compares each wordmark `src` with its imported module value. Both wordmarks use `alt="FINEbank.IO"`; the test finds them by their card and sidebar containers.
